①用户画像 + 历史记忆 （你提出 · 深化设计）

2.1 两层画像模型

层字段来源刷新
静态层历史投诉次数 / 历史赔付总额 / 获取过的补偿类型（券/现金比）/ 会员等级 / 信用分 / 渠道偏好（12315偏好型？微博偏好型？）CRM + 工单系统案件结案时
动态层情绪曲线（每轮情绪值）/ 证据配合度 / 让步速度 / 确认信号灵敏度本对话实时推断（规则或 LLM）每轮

2.2 画像的双向消费（关键设计）

喂反贼 出题人格 = f(画像)：
  理性协商型 → 摆事实列损失，升级慢，重证据
  情绪主导型 → 感叹号多，攻势增益 +20%，但让步也快
  专业索赔型 → 引法条（消法/民法典），等级直接 Lv.2 起步
  职业敲诈型 → 试探底线话术，证据弱，走风控线
  多次维权老客 → 记忆升级加速（"上次你们就是这么说的"）

喂忠臣 策略先验 = f(画像)：
  高价值老客 → 预算上浮系数 ×1.5
  高信用分 → 举证要求放宽（strong 门槛降低）
  券敏感度低（历史拿过券但继续投诉）→ 内奸现金换券对此用户失效
待你确认的设计点：① 画像来源优先级——用户手选 / CRM 自动带出 / LLM 从对话首条消息推断，三种来源冲突时以谁为准？② 历史记忆的合规边界：赔付历史属于个人信息，跨案件调用的授权口径需要法务定义（建议：仅用统计特征，不回放具体案件内容）。

②资金池 （你提出 · 深化设计）

3.1 从单池到三池

池覆盖配置项耗尽行为
现金赔付池部分赔付 / 全额赔付日/月总量、单案上限、审批分级（专员自主额度/主管/法务）池空 → partial/full 自动禁用，技能坞置灰，只剩券+服务
权益券池优惠券 / 权益包总量、面额档位、有效期池空 → 券技能降级为纯道歉+加急
服务成本池专家通道工时 / 加急处理工时折算单价、日容量池空 → 专家通道排队（真实业务约束）

3.2 池间汇率——内奸的经济学基础

配置：1 元现金 = N 元券面额（如 1:3）= M 分钟专家工时

内奸〔Mode B · 现金换券〕的置换判定将基于汇率：
  置换收益 = (现金成本 − 券成本/汇率) × 成交概率衰减折损
  收益 > 0 → 触发置换压力（当前为 40% 固定概率，v3 改为汇率驱动）

3.3 与满意度目标的联动

资金池是硬约束，满意度目标是软目标：池耗尽时满意度预测再高也无法加码——此时引擎应提前触发"最优可用方案确认"（在池见底前主动锁定成交），而非硬扛到破裂。这是「预算见底」仲裁规则的业务化升级。

③满意度目标值 + 预测小模型 （你提出 · 深化设计 · 核心中的核心）

先说结论：引擎里的 resolution_score（解决率）就是满意度预测的 v0——它的定义正是"用户与系统达成一致的概率"（每轮按攻势强度×技能力度×成本累积）。v3 要做的是三件事：显性化（改名为成交概率并逐轮显示）、目标化（挂目标线）、动作化（达标/未达标触发策略）。

4.1 三版演进路径

版本形态特征说明
v0（已实现）规则累积分攻势增益、技能力度、成本（隐含在技能选择里）可解释、零成本、已驱动全部现有机制
v1（轻量模型）逻辑回归 / GBDT攻势类型one-hot、等级、证据强度、轮次、累计成本、已用技能序列、攻势压力、均衡信号、情绪词密度、确认信号沙箱对练全记录 = 天然训练集（成交回合=正样本、仲裁终止/破裂=负样本）；真实对话回流增量训练
v2（LLM 判读）每轮对话后 LLM 输出 0-100 成交概率 + 影响因子全对话上下文可解释性弱于 v1，建议双跑对校（v1 保底，v2 拟人）

4.2 目标值配置与达标动作（与 v2.3 成交机制的衔接）

配置：按 case 类别设目标值（示例）
  物流破损类 ≥85% ｜ 商品质量类 ≥80% ｜ 服务纠纷类 ≥65% ｜ 涉法类 ≥50%（转法务前的止损线）

每轮预测输出 → 三段动作：
  预测 ≥ 目标 ──────→ 忠臣主动求确认（"您看这个方案可以吗"）→ v2.3 成交检测 → 收尾
  预测 ∈ [目标-15, 目标) → 继续当前路径，但史官在史册标注"接近达标，观察一轮"
  预测 < 目标-15 连续 N 轮 → 换策略（升档技能）/ 升专家通道 / 预警人工介入

UI 呈现：解决率进度条上加目标刻度线（金色横线），沙箱与真实对话同一把尺子

4.3 训练数据闭环（这个产品的隐藏金矿）

沙箱每轮对练全记录（对练原文+四角色思考+成交/破裂结局）+ 真实对话回流 = 持续增长的标注数据集。反贼越强，预测模型越准——这是三国杀架构对预测模型的间接贡献：刁钻场景覆盖度决定模型泛化能力。

待你确认的设计点：① 目标值按 case 类别配置还是全局一个值？② 未达标 N 轮的 N 取多少（建议 2）？③ 预测模型的落地顺序——先上 v0 显性化（改 UI 即可）还是直接训 v1？

贰我建议补充的配置项（除你三项之外）

A. 技能池白名单 + 真实成本标定 P0
作用对象：忠臣技能库 ｜ 配置层：对练级
当前技能成本是演示单位（¥60/¥150/¥800/¥3,000）。业务侧需标定：每技能的真实成本、可用性开关（如"本案禁用全额赔付"）、审批档位。这是从演示到落地的第一步。
B. 成本-效果 Pareto 权重 P0
作用对象：内奸模式选择 + 史官最优片段判定 ｜ 配置层：对练级
省钱 ↔ 满意滑杆（0-100）。省钱端：内奸 Mode B 频率↑、史官偏好低成本片段、蒸馏技能偏"权益置换法"；满意端：反之。这是三国杀的灵魂参数——它决定蒸馏出的技能长什么样。
C. 转人工阈值（安全网三触发） P0
作用对象：全局 ｜ 配置层：体验级
① 满意度预测连续 N 轮 < 下限且无改善；② 红线命中（人身损害/未成年/欺诈嫌疑/大V舆情）；③ 索赔金额超单案上限。触发后：暂停自动决策 → 生成案件摘要移交人工（沙箱继续后台推演供人工参考）。
D. 仲裁优先级声明 P0
作用对象：全局策略仲裁 ｜ 配置层：系统级
成本权重与满意度目标冲突时谁赢？两个预设档：满意度优先（成本上限为硬约束）/ 成本优先（满意度下限为底线）。业务侧声明后，内奸的行为语义随之改变（成本优先时内奸是"成本守门人"，满意度优先时内奸是"质量督察"）。
E. 反贼原料源 P1
作用对象：剧本库 ｜ 配置层：场景级
接历史工单后：按渠道/品类/时间窗/赔付结果选择（如"近90天食品类差评工单中最终升级投诉的子集"）——真实数据喂养的反贼才是专业反贼。支持与手动灌入混编。
F. 内奸强度与模式偏好 P1
作用对象：内奸 ｜ 配置层：对练级
干预预算（0=纯验证 / 3=标准 / 6=地狱）、模式偏好（加压为主/降本为主/均衡）、现金换券激进度（汇率驱动/固定概率）。用户反馈"需改进"时的预算加成幅度也可配。
G. 对练深度与收敛阈值 P1
作用对象：史官仲裁 ｜ 配置层：对练级
回合上限（快速验证 6 / 标准 12 / 深度打磨 20）、收敛条件（均衡阈值/稳定轮数）、停滞保护轮数、预算见底动作（止损蒸馏 / 最优可用方案锁定）。
H. 话术风格 + 谈判节奏 P1
作用对象：忠臣语言层 ｜ 配置层：体验级
风格：正式 / 亲和 / 专业简洁（影响回复模板选库）。节奏：激进让步（首回合即出实质方案）vs 稳健（先验证诉求再报价）——影响 chooseSkill 的首技能倾向。
I. 技能版本灰度 + 数据回流策略 P2
作用对象：技能发布 / 闭环节奏 ｜ 配置层：系统级
新技能 v(N+1) 先 20% 流量与 v(N) 对照，满意度预测无显著差异才全量。回流：真实对话每 N 轮自动回灌沙箱（自动闭环）vs 仅人工反馈触发（可控闭环）。
J. 红线集合 P1
作用对象：转人工+法务 ｜ 配置层：系统级
默认红线（人身损害/食安/欺诈）之外，业务可增补：涉未成年人、涉舆情大V、涉监管在办案件、涉上市敏感期。红线命中即出沙盒、进人工。
