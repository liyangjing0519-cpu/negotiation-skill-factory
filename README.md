# 谈判技能工厂 · 体验版

把「索赔谈判」变成可蒸馏、可迭代、可复用的技能资产。

## 核心闭环

灌入疑难场景 → 四角色沙箱对练（反贼发难 / 忠臣应对 / 内奸搅局 / 史官仲裁）→ 蒸馏技能 → 加载体验 → 用户反馈回流重训 → 版本迭代。

## 主要功能

- **四角色平等制衡**：反贼制造压力、忠臣在成本与规则内化解、内奸打破假均衡、史官记录仲裁，非 planner-executor 金字塔。
- **大模型自主决策**：体验环节由 LLM 判断阶段、从全部可用技能（含沙箱新增）中自行选招，语言始终贴合用户提问，不暴露机制。
- **反馈即训练**：用户反馈驱动技能重训，回沙箱加压复测后再沉淀为新版本。
- **安全网**：红线命中 / 金额超限强制提示转人工；v1 规则与 v2 模型双跑对校，分歧超阈值标记复核。

## 运行

打开 `index.html` 即可，或 `python3 -m http.server 8000` 后访问 `http://localhost:8000`。

配置中心 → 系统级 → 大模型自主决策，填入 OpenAI 兼容的 endpoint / model / API Key 即可启用；未配置时自动回退内置规则引擎，全功能离线可演示。
