叁三步用户流程详解

第一步 · 疑难杂症灌入

  • 输入形态：多轮对话原文（一行一轮，按句/行切分为剧本轮）或场景描述
  • 引擎实时解读（打字即反馈）：攻势类型/等级/预计增益、证据强度（强→可解锁全额与伤害下限；弱→高要价将触发合规拒绝）、人身损害标记、预计剧本轮数
  • 快捷模板 4 种（B2B 停业+监管 / 人身损害+舆情 / 疑似欺诈空包裹 / 经销商批量索赔）
  • 场景队列：可增删、可混合来源（手动灌入 + 反馈回灌），进入第二步按顺序对练

第二步 · 沙箱四角色对练

  • 剧本构造：每场景 ≤3 原文轮 + 2 升级轮（按类型自动生成，如舆情型→"视频已剪好就差标题/今晚八点上热搜"），总量截断 12 轮
  • 📂 对练全记录（v2.1 新增，折叠面板）：对练区下方折叠入口，展开后逐回合留档——📜 对练原文（反贼台词 + 忠臣谈判应答全文）+ 四角色内部决策思考过程：
    • 反贼思考：剧本来源、关键词命中明细（如「12315、投诉」→合规威胁+3）、金额/情绪/长度信号、等级与增益公式、记忆库状态（同型出现次数与升级判定）
    • 忠臣思考：证据档案粘滞判定（翻案/降级/维持）、决策树逐级推演（①反欺诈线→②法律线→③蒸馏技能匹配/伤害下限→④可用池→⑤覆盖贪心→⑥换招规避）、预算校验
    • 内奸思考：三触发线评估（均衡≥55/解决率≥88/单轮成本≥¥1200）、模式选择理由、目标锁定逻辑（优先最近使用的高价工具）、现金→券置换判定
    • 史官研判：效率量化（化解÷成本）、解决率/均衡/攻势走势、仲裁检查（死局/停滞/预算信号）
  • 🏷 逐回合标注 + 技能批注（v2.4）：每条对练记录可打标注（金额不明 / 答非所问 / 误判成交 / 漏判成交 / 该收不收 / 绕弯拖延 / 话术生硬 / 机制外露 / 表达啰嗦），技能卡可写累积批注；标注与批注写入 skill 文件 持久化。再次对练前先读取全部历史标注 + 批注 → 更新 skill 再开练，并解析成统一训练指令贯穿四角色（反贼据此发难 / 忠臣调整话术与直答 / 内奸决定加压或降级 / 史官调整研判重点）
  • 反馈驱动调整：「需改进」反馈会追加一轮「上次的方案我不接受！直接升级处理！」且内奸干预预算 3→4
  • 界面：左侧大竞技场 + RPG 对话框；右侧史册面板（记录 feed + 效率研判 + 进度）与控制条
  • 速度：沙箱模式 0.55× 倍速（打字机 13ms/字），完整一轮约 40-60 秒

第三步 · 加载技能 · 体验谈判

  • 点击「📦 加载技能」：技能卡进入忠臣技能库（金框 + v 版本徽章，最多同时 4 个）
  • 技能真实生效：聊天消息的攻势类型与技能 matchType 匹配时，忠臣优先使用该技能（弹道金色、应答话术引用技能路径）
  • 技能用例剧本：史官依据灌入场景自动生成 3 条示例消息，一键发送体验
  • 右侧 = 内部博弈可视化（与 v1 相同：你的每条消息 = 一回合三方博弈 + 史官记录）
  • 反馈闭环（v2.2 结构化，门控式交互）：折叠面板内第一级为总评——点 👍（技能有效）直接提交总评，无表单；点 👎（需要改进）才展开第二级：三方面结构化反馈表单（字数不限，均可留空，分路回灌）：
    • 💬 语言交互方面（话术/语气/共情表达）→ 回灌史官：登记为蒸馏技能的话术层注记（供话术库迭代）
    • 📈 进展推进方面（节奏/轮次/方案速度）→ 回灌反贼：下一轮自动注入节奏施压回合（如"我不想再耗了，今天必须直接进入实质方案"——由"慢/拖/久/来回"等关键词触发）
    • ♟ 策略决定方面（赔付工具/金额/方案选择）→ 回灌反贼+忠臣：下一轮自动注入策略挑战回合（如"别再拿优惠券糊弄我，我只接受现金赔偿"——由"现金/券"等关键词触发）
    • ✦ 收尾能力（v2.3，跨方面检测）→ 回灌沙箱：三方面反馈中含"重复/满意/询问/达成/一致/成交/收尾/结束/确认"等词 → 下一轮剧本末尾追加成交确认测试回合（"行吧，那就按这个方案办！"），验证忠臣能否正确停止报价并收尾
    提交后三方面反馈 + 对话原文回灌第一步场景队列 → 自动新一轮对练 → 蒸馏 v+1 技能（版本注记完整记录三方面原文）。
    v2.4 统一训练语料包：提交反馈时不再只传"反馈文字 + 用户台词"，而是打包 ①体验对话原文（用户+专员双方应答）②四角色思考链（反贼/忠臣/内奸/史官每回合的前因后果）③对话标注原文（逐回合 tag + 说明）④技能批注原文（全量累积） 四份语料，一次性交给大模型（未启用时规则引擎兜底）重训生成新 skill；重训卡片会显示"本次投喂了哪几类语料、各多少条"，链路可核对。
    ※ 交互门控：👍=总评直提（巩固路径），👎=展开三方面表单（改进路径），二者互斥切换；若在谈判回合进行中提交反馈，系统会显示「⏳ 等待当前回合结束，即将自动开练」并自动排队启动（防静默丢失）；提交按钮在排队期间禁用防重复提交
演示模式：URL 加 #demo 自动灌入 2 条场景并跑完整对练；#demo2 额外自动完成 加载技能→发送匹配消息→提交反馈→再对练 的完整闭环（内部测试用）。

4.3 版本迭代规则（反馈闭环）

👍 技能有效 → 新一轮侧重巩固 → 同名技能 v+1（力度小增，注记"打法予以巩固"）
👎 需要改进 → 反贼追加"直接升级"轮 + 内奸预算+1 → 复测通过后 v+1（注记"反贼加压复测通过"）
主导技能 = 已加载技能 → 技能血统延续：同名迭代增强（力度 +2+解决率/12），而非另起新名

4.4 加载与生效

  • 加载后进入忠臣技能库（与基础 6 式并列，金框标识）；场景类型匹配 → 优先使用（体验路径：弹道金色、对白「这题我练过！」、应答引用技能打法）
  • 内奸同样可以对蒸馏技能降级/冻结（它也是"工具"）——沙箱中被打磨过的技能才是可交付的
  • 同时最多加载 4 个技能（超出时淘汰最旧）

柒训练闭环与收尾判定（v2.4 新增）

7.1 为什么需要这一版：从"改描述"到"改行为"

v2.3 之前，第三步反馈回流存在结构性断点：重训只改变技能的描述文字（pathDesc / fbNote），而真正决定行为的开关（成交判定）是写死的；标注/批注里关于"收尾"的信号被赋值后从不被决策代码读取（"死信号"）。结果是练再多轮，行为纹丝不动。v2.4 把这些开关全部改造成可被训练信号驱动的"活信号"。

7.2 skill 文件与累积学习

机制说明
skill 文件持久化蒸馏产出与反馈重训的技能写入 skill 文件（含版本 history）；同名升版本、保留标注与批注。存储于浏览器 localStorage，面板内可查看当前版本/标注数/批注数/更新时间
逐回合标注对练全记录每回合可打 tag + 补充说明，累积保存（最多 100 条）。再次对练前读取全量标注 → 更新 skill 路径与力度
技能批注技能卡可写批注，累积保存（最多 50 条，不再覆盖）。批注原文直接进入统一训练语料包
统一训练指令标注/批注解析成四角色共享的训练指令：反贼生成针对性发难 · 忠臣调整话术/金额直答/成交拦截 · 内奸决定加压或工具降级 · 史官调整研判重点

7.3 统一训练语料包（第二步更新的真正输入）

提交反馈时，第二步重训收到的不是零散文字，而是一份完整语料包：

① 体验对话原文     用户原话 + 专员应答（双方，最近 12 轮）
② 四角色思考链     每回合 反贼/忠臣/内奸/史官 的内部推理与前因后果（最近 8 组）
③ 对话标注原文     逐回合 tag + 说明 + 该回合原文（全量累积）
④ 技能批注原文     全部历史批注（全量累积）
⑤ 三方面反馈       用户总评 + 语言/进展/策略 + 收尾检测

大模型提示词要求逐条吸收标注与批注里的具体要求（写入 signalsApplied），让新技能的招式路径真实反映语料暴露的问题；未配置密钥时规则引擎回退，流程不中断。重训卡片显示各类语料条数，可核对本次到底喂了什么。

7.4 可训练收尾判定（口语 + 活信号 + 语义复核）

能力说明
口语归一判定"行了 / 行吧 / 好的 / 嗯嗯 / 没问题 / 那就这么定了 / 妥了"等高频口语全部识别为确认成交（31 类实测全过）；"赔多少 / 不行 / 再考虑 / 发我看看"等仍正确不判。修复了"用户说行了却不终结对话"的核心投诉
双向可训练严格度标注「误判成交」→ 收紧（未明确同意不收尾）；标注「漏判成交 / 该收不收」→ 放宽（果断收尾）；批注里出现的口语（如"好嘞"）自动学成自定义确认词；反馈里"说了行就别再问"也会调整。严格度 strict / normal / loose 跨对练累积
已报方案硬门槛收尾前必须确认对话里真的报过方案（金额/到账/全额/权益券等实质承诺），开场白"我是赔付专员"不再误判；修复共情话术下 lastOfferSkill 为空导致说"行"也不收尾的死锁
LLM 语义复核（可选）配置中心「成交收尾判定」区可开启。开启后，规则未判成交时把"用户原话 + 最近专员回复"交大模型判断是否明确同意；未启用 / 无密钥 / 调用失败自动回退规则，演示不中断
设计原则：规则白名单是准入与兜底（快、可解释、离线可用），大模型是语义增强（处理模糊表态）。训练信号直接作用于判定参数，而非仅写入描述——这是 v2.4 与之前版本的本质区别。
